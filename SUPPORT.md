# Support

Ultraviolet is public alpha software. The project welcomes early usage
questions, build reports, conformance reports, documentation fixes, and focused
compiler/runtime contributions, but it should not be treated as a mature
production dependency.

## Questions

Ask public questions in GitHub Discussions:

https://github.com/blacklight-foundation/ultraviolet/discussions

You can also contact the project through:

- Email: contact@blacklight.foundation
- X: https://x.com/blacklight_fdn

## Issues

Use GitHub Issues for actionable repository work:

- Compiler or runtime behavior that appears non-conformant with the
  specification.
- Build, package, or vendored-toolchain failures.
- Missing or incomplete HelloUltraviolet conformance coverage.
- Stale, missing, unclear, or incorrect documentation.

Compiler bugs must identify the specification area, obligation, inference,
judgement, diagnostic rule, or normative text that the current behavior violates.
Desired language behavior without current specification support belongs in a
GitHub Discussion first.

## Security

Do not report vulnerabilities in public issues or discussions. Use GitHub
Private Vulnerability Reporting for this repository. See `SECURITY.md`.

## Conduct

All project spaces follow `CODE_OF_CONDUCT.md`. Conduct reports go to
`@cursivecrow`.
